## LinkedIn

Bitcoin price prediction is the world's most popular machine learning failure. Every quant trader and grad student has tried it. So why try it again?

Because if you run the experiment honestly - same data slice, same metrics, same rules - you learn something that the viral threads never tell you.

I ran seven experiments. Zero-parameter naive baseline. ARIMA with 3 parameters. XGBoost on 31 engineered features. LSTM with thousands of weights. Temporal Fusion Transformer with tens of thousands. Zero-shot foundation models (Chronos-2 and TimesFM 2.5) with up to 200M parameters that have never seen Bitcoin. And finally, fine-tuned foundation models that have.

Same Bitcoin. Same window. One scoreboard.

The result is a ladder of model classes, with surprises at every rung. Capacity does not equal skill. Point error and trading metrics measure different things. The 3-parameter ARIMA beats the 30 000-parameter Transformer on direction. Zero-shot transfer is harder than the marketing.

This is article 0 of an 8-article series. Each one stands alone, but read in order, they tell a coherent story about what each model class actually does to a hard problem - and how to evaluate forecasts honestly.
