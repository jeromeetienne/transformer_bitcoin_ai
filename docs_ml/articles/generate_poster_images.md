# Poster Image Prompts

One paste-ready prompt per article. Each prompt enforces the same design
system so the seven covers read as a single series: a deep navy background,
a single accent color (electric amber pulled from Bitcoin orange but
desaturated for a professional feel), off-white serif/sans typography, a
left-aligned text block, and a subtle method-specific motif on the right
that never competes with the headline.

## Shared design system (copied into every prompt)

- Canvas: 1200 x 644 pixels, designed for LinkedIn feed and mobile preview.
- Layout: text block occupies the left 60% of the canvas, visual motif occupies the right 40%, both vertically centered.
- Background: deep navy (#0B1A2B) with a faint diagonal noise texture; a thin amber rule (#F2A93B) sits 48px below the title.
- Typography: title in a modern geometric sans (Inter Tight, Söhne, or similar), 64-76px, weight 700, off-white (#F4F1EA); subtitle in the same family, 26-30px, weight 400, amber (#F2A93B); small uppercase tag "Bitcoin ML Series - Article N of 7" in 16px tracked letters above the title.
- Motif: monochrome amber line art on the navy field, low contrast, treated as a watermark - never more than 35% of the canvas width, never overlapping the title.
- Mood: editorial, restrained, suitable for a technical audience on LinkedIn.
- Mobile test: every word in the title and subtitle must remain legible when the image is rendered at 360px wide.
