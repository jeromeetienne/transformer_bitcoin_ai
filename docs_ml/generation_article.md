# Prompt
- study the README.md in this folder, which lays out the principles for the article series. Especially about 'folder hierarchy' and 'requirements'.
- for each article
  - First, create the outline of the articles, saved as `<slug>.outline.md` in the article's folder.
  - then, generate the full article based on the outline, saved as `<slug>.article.md` in the article's folder, and following the style guidelines in STYLE.md. The article should be detailed, with code snippets and explanations, and should be self-contained. It should also follow the linking requirements, ensuring that all links point to GitHub at the head of the default branch.
