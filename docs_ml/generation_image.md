# Prompt

For each article in the series, write a self-contained image-generation prompt that I can paste into claude.ai to produce a professional cover image. Do not attempt to generate the images yourself — only produce the text prompts.

Save the resulting prompts to [articles/generate_poster_images.md](articles/generate_poster_images.md), one section per article (heading = article title, body = the prompt).

## What each prompt must specify

**Technical Requirements:**
- Image dimensions: 1200x644 px (optimized for LinkedIn)
- Ensure readability on mobile devices (portrait orientation)

**Design Guidelines:**
- Minimize graph/chart size — keep data visualizations subtle and secondary
- Use large, legible typography as the primary focus
- Ensure all text is clearly readable at small sizes (mobile viewing)
- Maintain a clean, professional aesthetic suitable for professional audiences

## Per-article content the prompt must include

- The exact article title to render as the dominant text
- A short subtitle or tagline tied to the article's specific topic 
- A concrete visual motif that reflects the article's method - kept subtle and secondary to the typography
- A consistent color palette and layout direction across the series so the covers read as a set
